# 本地 GPT TTS v1 定义

本地 GPT TTS 指在自有主机上运行 **GPT-SoVITS 推理和 Absolute Solver TTS 网关**。Cortico/Coo 提供要说的文本并选择已注册的音色；GPT-SoVITS 生成波形。模型权重、参考音频和音色配置留在推理主机。这里的「本地」允许同机或通过 SSH 接入自有模型主机；语音合成不依赖云端。Cortico 的对话模型是否在本地是另一个部署选择。

~~~text
Cortico / Coo TTS World
  → OpenAI 兼容 POST /v1/audio/speech
  → Absolute Solver TTS 网关 :18080
  → GPT-SoVITS api_v2 :9880（推理机回环）
  ← 完整 PCM WAV
  → Cortico tts.voice 事件及音频附件
  → Live2D 播放，或由主机将 WAV 交付给 MicroDuck 的 ALSA 扬声器
~~~

## 部署与算力

| 角色 | v1 约定 |
| --- | --- |
| 合成主机 | 网关与 GPT-SoVITS 同机运行，推理端口只绑定回环。Coo 同机时直接访问网关；异机时优先经已校验主机公钥的 SSH 转发，Coo 仍用自己的回环地址访问。客户端密钥只在 Coo/网关侧。 |
| CPU 档 | 作为共享设备的可复现验收档，和 GPU 档使用同一套音色及权重。CPU 档实测能产出有效语音样本；一次约 26 秒的结果只证明可用。 |
| GPU 档 | 作为有足够显存时的低延迟档。部署前用同一短句验证。GPU 和 CPU 由运维显式选择，v1 没有自动切换，也不替其他工作负载释放显存。共享主机从单并发开始验收。 |
| MicroDuck | 播音端，仅接收已合成的 WAV。`robot.sound` 继续负责预置叫声；自然语音通过显式指定的 ALSA 设备播放。模型、网关和客户端密钥不部署到鸭身。 |

## 适配合同

- **合成请求：** `POST /v1/audio/speech`，使用 Bearer 客户端密钥，发送 `model`、`input`、已注册的 `voice` 和 `response_format: "wav"`。Coo 的 `tts-1` 是兼容接口里的模型名。每次合成从音色档案取参考音频、参考原文和默认语言；实际 GPT/SoVITS 权重来自上游进程启动时加载的配置，或由管理员显式切换。登记音色的权重路径和请求中的 `voice` 都不会按请求自动加载权重。v1 用固定的权重组合验收。
- **语言：** 网关顺序为显式 `text_lang`、字形推断、音色默认语言；参考音频语言独立由音色档案指定。当前 Coo 发的是 `lang`，网关不将其视作 `text_lang`，所以这一组合不能依赖 Coo 的语言提示强制切换。需要强制指定时使用支持 `text_lang` 的客户端；Coo 若要支持该能力，先补字段映射和中日文混合测试。
- **音频：** v1 一次请求返回一个完整 WAV。当前 Coo 请求可带 `sample_rate`，网关不会据此重采样，以实际 WAV 头为准。MicroDuck 验收接收 8–48 kHz、16 位、单/双声道 PCM；若目标设备需要转换，由播放适配负责，并保留原始文件。Live2D 的 SSE 传事件和附件地址；本版没有边合成边播、跨端打断或自动向 MicroDuck 推送。
- **交付：** 正常对话取新 `tts.voice` 的附件，关联事件游标、音色和 Clip ID。控制台试听用于独立验证同一真实合成服务。板端按 SHA-256 校验后再调用 ALSA，回报设备、摘要和播放器退出码；现场听辨确认声源与内容。
- **失败：** `/healthz` 的上游在线只说明探活成功。合成返回空、损坏或全静音 WAV 时，网关应报 `502` 并记录原因；播放脚本也会拒绝数字静音。读对了内容需要 ASR 或人工听辨确认。

## 当前证据与验收

2026-11-19，Coo 试听经本地回环入口和 SSH 转发调用自有网关，CPU 档返回真实 WAV：Clip `57458cd6`，32 kHz 单声道、16 位、5.82 秒，端到端取回约 26.3 秒。已通过非静音、格式和 SHA-256 本地校验。GPU 档同次测试曾因显存耗尽，旧网关仍返回 HTTP 200 和 1 秒全静音。仓库修复和离线回归已覆盖这类响应；实测使用的远程网关尚未部署此修复。

正式验收还要取得一条来自真实 Cortico 对话的 `tts.voice` 事件及附件，核对语音内容，并到 MicroDuck 上验证扬声器与回执。按 [MicroDuck 验收手册](microduck-acceptance.md) 执行。若后续要求实时分块，将它作为独立协议能力验收，指标以**第一块可播放的 PCM**为准。
